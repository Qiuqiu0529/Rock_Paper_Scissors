# 石剪布实验室：网页版模拟器

打开网站即可在表单中设置玩家策略、赛程分组、阶段人数与场次、胜平负分数、手势加分条件与每阶段上限，再运行模拟并查看交互式结果。计算在当前浏览器中进行，无需安装 Python 或第三方库。

**本地使用：直接双击 `rps_web.html`。** 这是完整的单文件离线应用，已包含模拟引擎、后台计算与报告模板，不需要启动服务，也不需要联网。

## 配置与运行

1. 选择“原始规则”“剪刀奖励”或“进阶实验”预设。两个主要预设都包含100人、四种策略各25人；初赛随机分10个赛程组，每组10人组内循环，每人9场后按全体积分选30人；决赛30人重新随机分3组、每人9场，按全体积分选10人。每届585局，默认重复1000届。
2. 在“玩家策略”中添加或修改分组。每组设置人数和策略；给一人设置独立策略，可建立人数为1的组。随机策略的三项概率以百分比输入，合计100%。
3. 在“比赛流程”中修改阶段，指定每人场次、赛程组人数、晋级人数，以及排名积分是否清零。赛程组人数留空即全阶段随机配对；填写时必须为能整除参赛人数的偶数，每人场数须小于组人数。同阶段不重复遇到对手，晋级名额按全阶段积分统一排序，不按赛程组分配。
4. 在“积分规则”中设置胜、平、负基础分与各手势加分，选择哪些结果有资格获得加成，并按手势设置每阶段最多奖励次数和最多累计加分。留空表示不限。加成次数与金额对每位玩家在每个阶段重新计算；达到上限后照常获得基础分。胜负关系仍是石头胜剪刀、剪刀胜布、布胜石头。
5. 设置重复模拟届数与随机种子，检查右侧人数流转和预计对局量，然后点击“开始模拟”。运行期间可点击“停止本次模拟”；停止会取消当前计算，不会把未完成的比赛算作完整结果。

阶段独立计分、阶段策略切换、策略状态跨阶段延续等选项可在“完整 JSON 配置”中编辑。`scoring.bonus_outcomes` 为可奖励结果数组（如 `["win","draw"]`），`scoring.hand_bonus_limit` 是每手势、每人、每阶段的最多奖励次数，`scoring.hand_bonus_cap` 是对应累计最多加分；`stages[].group_size` 是赛程组人数，留空或 `null` 为不分组。阶段的 `scoring` 可以覆盖全局相应字段，未写字段继承全局。旧配置仍可导入，未指定加成条件时沿用原来胜平负均有奖励、没有上限的行为。新的网页配置字段只由网页版支持，不能直接交给旧版 Python 脚本运行。

每阶段参赛人数必须为偶数；后面还要比赛时，阶段选出人数也须为偶数。最后阶段可选任意人数，包括选出1名冠军。每人场次须在1到该阶段人数减1之间；分赛程组时还须小于组人数。

## 查看与保存结果

完成后进入“可视化结果”。可以比较策略组的最终入选率、单局胜率、非平局胜率和每局得分，查看阶段流转与各组条件晋级率，再按阶段、轮次或玩家查看首届比赛记录与排名。

- 策略与阶段汇总覆盖全部重复模拟；积分分布、逐轮对局和玩家轨迹只展示首届。
- 单局胜率以实际打过的所有局数为分母，包含平局；非平局胜率仅以胜局加负局为分母，全为平局时该项无定义。
- 各组最终入选率按“入选人次 ÷（该组人数 × 模拟届数）”计算；阶段晋级率只以实际进入该阶段的人次为分母。

点击“下载离线报告”保存一份自包含 HTML，可直接双击查看或单独分享，打开报告不需要联网。重新修改设置后，需要再次模拟才能得到新结果；旧报告仍代表上次已完成的实验。

## 策略会怎样影响结果

网页支持独立随机、固定手势、按序循环、模仿上一场对手，以及克制上一场对手。后两种策略只知道自己上一场对手已经出的拳，看不到当前对手本局的选择。循环也不等于随机：相同序列和起点的玩家可能同步出拳、持续打平。

原始预设按胜2、平1、负0计分，无手势加分；均匀随机、偏剪刀、偏布、偏石头各25人，后三组偏好的手势概率为60%、其余各20%。剪刀奖励预设沿用这100人的策略和基础分，仅在剪刀胜或平时加0.5分，每阶段至多奖励6次且累计最多加3分；剪刀输时没有加成。原始预设同分先比较胜局数，再公开抽签。剪刀预设同分先比较胜局数，仍相同则比较**用剪刀取胜的局数**，最后公开抽签；单纯多出剪刀或剪刀打平、打输不会增加这个同分指标。若阶段设置为积分清零，该阶段的胜局和剪刀胜局也重新统计；若选择结转，则一并结转。设自己出石头、剪刀、布的概率分别为 `p石、p剪、p布`，对手对应概率为 `q石、q剪、q布`：

```text
单局胜率 = p石 × q剪 + p剪 × q布 + p布 × q石
```

对手均匀独立随机时，自己的任何固定出拳概率都对应三分之一单局胜率。偏剪刀是否有利，取决于实际对手出布与出石头的比例；手势加分、同分规则、阶段清零和后续对手构成则会进一步影响最终入选率。应重复模拟，并尽量每次只改变一个因素。

网页和 Python 使用不同的伪随机数算法：网页中相同配置与种子可以复现，但与 Python 使用相同数字种子不会得到相同对阵或出拳记录。

## 浏览器版范围

支持最多1000人、10000届，所有届累计最多2000万局；实际运行速度与设备性能有关。随机种子必须是 JavaScript 安全整数，绝对值不超过 `9007199254740991`。

积分按精确十进制数计算和比较。JSON 中很大的整数积分请写成字符串，避免导入前被 JavaScript 数值舍入；单项积分最多28位有效数字，非零数值的数量级为 `10^-100` 到 `10^100`。概率使用普通数字，取值0至1且合计1。

## 可选：运行多文件网站源码

单文件 `rps_web.html` 可直接打开。如果需要运行 `rps_web_package.zip` 中的多文件网站源码，将其完整解压，在包含 `index.html` 的目录打开终端，运行：

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

随后在浏览器打开 [本地模拟器](http://127.0.0.1:4174/)。服务仅绑定本机地址。关闭时在终端按 `Ctrl+C`。多文件版本通过本地服务读取 Worker 与报告模板；单文件应用和导出的离线报告都可以直接双击打开。
