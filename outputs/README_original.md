# 原始石头剪刀布：无额外积分模拟

`rps_original.py` 是独立脚本，使用 Python 3.10+ 标准库，无需安装依赖，也不依赖原来的奖励版脚本。

## 规则

- 初赛：100 人，每人随机匹配 5 位不同对手，取前 30。
- 决赛：30 人清零重算，每人随机匹配 9 位不同对手，取前 10。
- 默认共 385 场、14 轮。同阶段对手不重复，跨阶段可以再次相遇。
- 石头胜剪刀、剪刀胜布、布胜石头，同拳平局。
- 胜 2 分、平 1 分、负 0 分；三种拳都没有额外积分。
- 同分先比较胜局数，仍同分则随机抽签；剪刀次数不参与排名。
- 每人每局按照设定概率独立出拳；不观察对手，不根据历史调整策略。

旧脚本的 `--scissors-bonus 0` 只取消额外积分，仍保留“剪刀次数优先”的同分规则。
本脚本把该同分优先也去掉，得到三种拳地位对称的原始对照。

## 运行

在脚本所在目录运行，默认所有人三种拳各有 1/3 概率：

```powershell
python rps_original.py --show-rounds
```

统一设定概率，依次为石头、剪刀、布，概率和必须为 1：

```powershell
python rps_original.py --probs 0.2 0.6 0.2 --runs 1000 --seed 42
```

给不同玩家设置不同概率，使用现成的策略组配置：

```powershell
python rps_original.py --config strategies.example.json --runs 1000 --seed 42
```

此配置为 40 名均匀策略、30 名偏剪刀策略、30 名偏石头策略。
配置文件只规定出拳概率，不会把同一策略的人分在同一比赛组。玩家间仍随机匹配。

赛制参数保留：

```powershell
python rps_original.py --prelim-rounds 7 --finalists 30 --final-rounds 9 --runs 1000 --out-dir original_more_games
```

## 三种“胜率”

| 字段 | 定义 | 用途 |
|---|---|---|
| `*_win_rate` | 赢局数 ÷ 全部对局数，平局计入分母 | 单局获胜概率的实际估计 |
| `*_non_draw_win_rate` | 赢局数 ÷ 有胜负的对局数 | 排除平局后谁更占优势 |
| `qualification_rate` | 进入前 10 的人次 ÷ 全部参赛人次 | 最终晋级概率的实际估计 |

`prelim_qualification_rate` 是进入 30 人决赛的概率；`conditional_final_qualification_rate` 是已经进入决赛后再进入前 10 的比例。
某项条件下没有任何对局，或没有任何非平局时，相应比率为空，JSON 中为 `null`；不是 0。

`prelim_*`、`final_*`、`overall_*` 分别统计初赛、决赛、所有实际参赛阶段。
策略组的局胜率用该组总赢局数除以该组总对局数；晋级率用该组晋级人次除以“组人数 × 届数”。
初赛淘汰者每届只打 5 局，决赛选手一共打 14 局，因此不能统一用 14 或 99 作为分母。

## 什么决定胜率

设自己的石头、剪刀、布概率为 `(r, s, p)`，对手的对应概率为 `(R, S, P)`，双方独立出拳：

```text
胜率 w = r*S + s*P + p*R
平率 d = r*R + s*S + p*P
负率 l = r*P + s*R + p*S
每局期望积分 = 2*w + d = 1 + w - l
```

只出剪刀时，胜率就是对手出布的概率 `P`，平率是 `S`，负率是 `R`。
因此对手布多时剪刀有利，对手石头多时剪刀不利；取消奖励后，剪刀不存在天然优势。
另外，按积分晋级时不只看赢局率，因为平局也得分。

如果对手每局均匀随机出拳，无论自己用什么固定概率，单局胜、平、负率都为 1/3，每局期望积分为 1。

如果全员使用相同分布 `(r, s, p)`，则：

```text
胜率 = 负率 = r*s + s*p + p*r
平率 = r*r + s*s + p*p
每人每局期望积分 = 1
```

例如所有人都采用 `(0.2, 0.6, 0.2)`，理论单局胜率是 28%，平率是 44%，非平局胜率是 50%。
大家策略相同且抽签公平，每个人进入决赛的概率仍是 30%，进入最终前 10 的概率仍是 10%。
极端情况下全员只出剪刀，单局胜率为 0，全部平局，非平局胜率没有定义，晋级由随机抽签决定。

最终晋级率还受这些因素影响：

1. **对手构成和抽签。** 异质玩家之间存在克制关系，5 个随机对手可能比全体平均更容易或更难打。
2. **阶段筛选。** 初赛会改变决赛的人群构成，因此决赛的胜率不必等于初赛胜率。
3. **每人局数。** 初赛只打 5 局就淘汰 70 人，随机波动较大。增加局数通常能减少赛果偶然性，但不会改变面对固定对手分布的理论单局胜率。
4. **积分与同分规则。** 相同胜率不一定产生相同积分，晋级还取决于平局和整个分数分布。
5. **策略是否调整。** 真实玩家可能观察后反制；当前脚本只模拟固定概率，没有学习机制。

随机种子影响一次模拟的样本，不改变上述理论概率。重复次数越多，估计通常越稳定；重复 1000 届不会让一届里的每个人多打比赛。

## 输出

默认保存到脚本旁的 `original_results`，与奖励版目录分开。同一目录再次运行会覆盖八个同名结果文件。

| 文件 | 内容 |
|---|---|
| `rankings.csv` | 首届全部 100 人的综合名次、最后参赛阶段和实际胜率 |
| `stage_rankings.csv` | 首届 100 条初赛、30 条决赛阶段排名 |
| `matches.csv` | 首届 385 场的双方出拳、胜负和得分 |
| `rounds.csv` | 首届 14 轮的过程摘要 |
| `player_summary.csv` | 全部届数每人的实际胜率、初赛及最终晋级率 |
| `strategy_summary.csv` | 全部届数各策略组的实际胜率和晋级率 |
| `strategy_matchups.csv` | 每种策略对每种策略的理论胜、平、负率及期望积分 |
| `summary.json` | 参数、首届前 10 名、策略统计及比率定义 |

CSV 是带 BOM 的 UTF-8，可用 Excel 打开。比率字段是 0 到 1 的小数。
`strategy_matchups.csv` 是固定分布间的数学计算，不是模拟估计，也不是实际配对次数；同名策略的行表示两个采用该策略的人对战。
`theoretical_prelim_*` 按初赛从其他 99 人随机抽取对手计算，排除了自己；它不代表经过筛选后的决赛理论值。
`overall_*` 包含进入决赛者的更多对局，比较初赛理论值时应使用 `prelim_*` 实测字段。

综合名次先排列决赛选手，再排列初赛淘汰者；不同阶段积分不能直接互相比较，决赛不带入初赛积分。

## 已运行的示例

附带的 `original_results` 为示例配置、种子 42、重复 1000 届的实际结果：

| 策略 | 实际单局胜率（含平局） | 最终前十概率 |
|---|---:|---:|
| 均匀策略 | 33.41% | 10.26% |
| 偏剪刀 | 30.09% | 6.62% |
| 偏石头 | 34.85% | 13.04% |

这个配置中偏剪刀玩家更容易遇到石头，偏石头玩家更容易遇到剪刀。优势来自对手分布，不能推广为石头总是最强。
改变策略组人数或概率，结果也可能改变。
